# Security policy

## Reporting a vulnerability

Do not report vulnerabilities in public issues. Report them privately with *Report a vulnerability* on the *Security*
tab of the affected repository and include:

- the affected repository and version: device firmware, the library `gridyard` or the Home Assistant integration
- what an attacker can do and under which conditions, for example from inside the home network
- steps to reproduce

Leave out setup codes, meter keys, Wi-Fi passwords and readings of your own meter; synthetic values are enough.

## Supported versions

Security fixes go into the latest release.
